# FanOrder 0.1.27 预发布版

适用于 Windows 10/11 x64（build 17763 或更新版本），仅适配[绿巨能（llano）V12Ultra（原 V16）AI 智能控温笔记本压风式散热器](https://item.jd.com/100211395916.html)（京东商品编号：100211395916；国补备案型号：SV107）。V11、V11 Pro、普通 V12 及其他型号不在适配范围内。

## 本版更新

- 程序的设备选择提示和「关于」页明确品牌、具体型号与适配范围，提供中英文说明。
- 安装包从当前源码构建，包含此前 0.1.25 安装包未提供的界面补丁，以及请求取消、响应超时和历史加载方面的可靠性改进。
- 保留温控曲线、手动调速、灯光预设、托盘操作与全局快捷键。

## 安装

- `FanOrder-0.1.27-Setup.exe`：Windows x64 中文安装程序，包含 .NET 10 运行时。
- `SHA256SUMS.txt`：安装包 SHA-256 校验值。
- 首次安装需要另行安装官方 PawnIO 2.2.0；安装包不包含或下载驱动。

升级前退出 FanOrder 托盘和 CLI。首次使用需要有人看护的设备配对与验证；不要让多个程序同时控制同一设备。关机停扇需要独立验证和显式启用，默认不启用。

## 验证范围

发布检查包括源码构建、模拟设备回归、合成界面检查和安装包载荷校验，不包含真实安装、升级或设备操作验收。
