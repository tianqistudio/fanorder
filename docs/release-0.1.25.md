# FanOrder 0.1.25 预发布版

适用于 Windows 10/11 x64（build 17763 或更新版本），仅适配[绿巨能（llano）V12Ultra（原 V16）AI 智能控温笔记本压风式散热器](https://item.jd.com/100211395916.html)（京东商品编号：100211395916；国补备案型号：SV107）。V11、V11 Pro、普通 V12 及其他型号不在当前适配范围内。提供温控曲线、手动调速、灯光预设和托盘操作。

- `FanOrder-0.1.25-Setup.exe`：中文 NSIS 安装程序，内含 .NET 10 运行时。
- `SHA256SUMS.txt`：安装包 SHA-256 校验值。
- 首次安装需要另行安装官方 PawnIO 2.2.0；安装包不包含或下载驱动。

安装前退出 FanOrder 托盘及 CLI，再运行安装程序。首次使用需要有人看护的设备配对和验证；不要让多个程序同时控制同一设备。关机停扇需要独立验证及显式启用，默认不启用。
